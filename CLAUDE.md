# Customized Quick Tile

## Overview

- android service of build a customized quick tile using kotlin language
- the quick tile showing an calculator icon
- when user tap the calculator icon, launch android default calculator app
- add comments to the source code

## Release Gradle Task

- build the apk and rename it into "quick-tile-demo-<tag>"
- code sign the apk use release key "quick-tile-demo-key"
- copy the apk to the root folder of this project
